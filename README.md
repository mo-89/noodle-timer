# カップ麺タイマー

カップ麺用のシンプルな3分固定タイマーです。ページを開いた瞬間に自動でカウントダウンが始まり、終了すると音で知らせます。ビルド不要の素のHTML/CSS/JavaScriptのみで、PWA(ホーム画面への追加)にも対応しています。

## 使い方

1. ページを開くと自動的に3分のカウントダウンが始まります(一時停止はできません)。
2. 「リセット」ボタンでいつでも3分からカウントダウンをやり直せます。
3. 時間になると音が鳴ります。「リセット」ボタンを押すと音が止まり、3分から再スタートします。

## ファイル構成

```
index.html      画面本体
style.css       スタイル
script.js       タイマーロジック・音声通知・PWA登録
manifest.json   PWA用マニフェスト
sw.js           オフライン表示用の簡易Service Worker
icons/          アプリアイコン(192px, 512px, iOS用180px)
```

## Service Workerのキャッシュ更新について

`sw.js` の `CACHE_NAME` はキャッシュ対象ファイルの内容から自動生成される「日付-ハッシュ」形式のバージョン文字列です。手動で書き換える必要はありません。

初回クローン後、以下のコマンドを一度だけ実行してgitフックを有効化してください。

```bash
git config core.hooksPath .githooks
```

これにより、キャッシュ対象ファイル(`index.html` / `style.css` / `script.js` / `manifest.json` / アイコン類)を変更してコミットするたびに、`.githooks/pre-commit` が `CACHE_NAME` を自動更新します。デプロイ(Cloudflare Pagesのgit連携)のたびに新しいキャッシュストレージが使われ、`activate` イベントで古いキャッシュが削除されるため、ユーザーは常に最新のファイルを受け取れます。

## ローカルでの確認方法

ビルド不要ですが、`file://` で直接開くと Service Worker が動かないため、簡易サーバーで確認してください。

```bash
cd noodle_timer
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くと確認できます。

スマホ実機で試す場合は、PC とスマホを同じWi-Fiに接続し、PCのローカルIP(例: `http://192.168.x.x:8000`)にスマホからアクセスしてください。

## ホーム画面への追加

- **Android Chrome**: メニューから「ホーム画面に追加」でインストールできます。
- **iOS Safari**: 自動のインストールバナーは出ないため、画面下に表示される案内の通り、共有ボタン→「ホーム画面に追加」から行ってください。

## 実装のポイント: 正確な経過時間の計算

`setInterval` の呼び出し回数を数えて秒を減らす方式だと、画面ロックやタブのバックグラウンド化でタイマーが間引かれたときにズレが生じます。このアプリでは代わりに「開始時刻(`Date.now()`)からの経過時間」を毎回計算し直す方式にしているため、しばらく画面を見ていなくても、戻ってきた瞬間に正しい残り時間が表示されます。タブが再びアクティブになった時 (`visibilitychange`) にも即座に再計算します。

## 音声通知に関するブラウザの制約について

- **自動再生ポリシー**: ブラウザはユーザー操作を伴わない音声の自動再生を制限することがあります。このアプリはページ内のどこかを一度タップ/クリックすると裏で音声再生の準備(AudioContextの起動)を行うようにしていますが、何も操作せずに離席した場合、タイマー終了時に音が自動再生できないことがあります。その場合は画面に「🔔 タップして音を鳴らす」ボタンが表示されるので、それをタップすると鳴らせます。**確実性を上げるには、タイマーを開始した直後に画面を一度軽くタップしておくことをおすすめします。**
- **画面ロック・完全バックグラウンド時**: とくに iOS Safari では、画面をロックしたりアプリを完全にバックグラウンドへ回すと、Webページの JavaScript 実行自体がブラウザ/OSによって一時停止されるため、その間は音を鳴らすことができません。この場合、画面のロックを解除してページに戻った瞬間に(経過時間の再計算により)音が鳴ります。「タイマーをセットして完全に画面から離れる」使い方をする場合、この制約は素のWebページ(PWA含む)である以上、回避が困難です。確実に鳴らしたい場合は画面をロックせずタブを開いたままにしておくか、スマホの物理的なキッチンタイマーとの併用も検討してください。
- **Android Chrome**: バックグラウンドタブでも比較的動作し続けやすいですが、省電力設定やOSの制約により同様に遅延・停止する場合があります。
